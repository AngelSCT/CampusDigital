//PARA VER LOS PASOS MAS DETALLADOS IR A EL ARCHIVO "COMANDOS-CORRER-APP-EXTENDIDO.txt"

PASO 1: CORRER PostgreSQL e iniciar XAMPP en caso de que se este usando

PASO 2: AEGURARSE DE TENER DESCOMENTADAS LAS EXTENSIONES DEL PHP.INI:

    ;extension=pgsql
    ;extension=pdo_pgsql
    ;extension=zip
    ;extension=intl
    ;extension=gd

PASO 3: CLONAR EL REPOSITORIO

    git clone https://github.com/AngelSCT/CampusDigital

PASO 4: ENTRAR A LA CARPETA DEL PROYECTO LLAMADA "campus-digital-app"
---ESTANDO ALLI EJECUTAR:
    composer update
    npm update

PASO 5: ENTRAR A POSTGRES Y CREAR LA BASE DE DATOS LLAMADA "campus_digital" SI YA LA TIENES PUES BIEN

PASO 6: AHORA CREAR EL ARCHIVO .ENV 
1) DENTRO DE LA CARPETA DEL PROYECTO "campus-digital-app" CREAR UN ARCHIVO LLAMADO ".env" (SIN COMILLAS)
2) DENTRO DE ESE ARCHIVO .env PEGAR EL CONTENIDO DEL ARCHIVO "archivo-.env.txt" EL CUAL ESTA EN LA CARPETA DE "archivos-adicionales"
3) ASEGURARSE DE TENER CORRIENDO EL SERVICIO DE POSTGRES Y CAMBIA LAS CREDENCIALES POR LAS TUYAS EJEMPLO: DB_USERNAME=campus_user Y DB_PASSWORD=postgres
4) GUARDAR LOS CAMBIOS EN EL ARCHIVO .env (ctrl + s)
5) UNA VEZ ESTE EL ARCHVO .ENV EJECUTAR LOS SIGUIENTES COMANDOS:

    php artisan key:generate
    php artisan optimize:clear

PASO 7: EJECUTAR LAS MIGRACIONES Y LOS SEEDERS: 
    php artisan migrate
    php artisan db:seed
    php artisan storage:link        NOTA:(SI ESTE FALLA O DA ERROR IGNORAR)

PASO 8(OPCIONAL): CORRER SEEDERS ADICIONALES [ESTOS SOLO SON PARA TENER DATOS DE PRUEBA ESTE SE PUEDE OMITIR]
    php artisan db:seed --class=RfidDemoSeeder
    php artisan db:seed --class=DashboardDemoSeeder

PASO 9: UNA VEZ QUE SE HAYAN CARGADO LAS MIGRACIONES Y LOS DATOS DE PRUEBA PODREMOS VER LA APLICACION FUNCIONANDO
//PARA ESTO USAREMOS 2 TERMINALES , AMBAS APUNTANDO A LA RUTA DE LA CARPETA DEL PROYECTO "campus-digital-app"

1)TERMINAL 1 COMANDO(EJECUTAR LARAVEL):

    DE PREFERENCIA:
        php artisan serve --host=0.0.0.0 --port=8000   

    USAR ESTE SI FALLA EL DE ARRIBA:
        php artisan serve

2)TERMINAL 2 COMANDO(EJECUTAR FRONTEND):

    npm run dev






PASO EXTRA: PARA HACER FUNCIONAR EL REGISTRAR CUENTA, RECUPERAR CONTRASENA CONFIGURAR SMTP DEL .ENV

#DENTRO DEL .ENV MODIFICAR LAS SIGUIENTES
